# Create Aether Product Roadmap

Create Aether is an experience engine for building atmospheric,
interactive and immersive interfaces for the web.

Development follows small, focused releases. Each release should improve
one part of the product without unnecessarily rewriting working systems.

## Product Principles

1. Improve one area exceptionally well.
2. Preserve working systems unless change is justified.
3. Keep the runtime modular and framework-friendly.
4. Make every release demonstrable.
5. Treat accessibility and performance as product features.
6. Ensure the playground produces configurations developers can use.
